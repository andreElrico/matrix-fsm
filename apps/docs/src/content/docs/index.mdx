## Why 2D Matrix State Machines?

Instead of deeply nested JSON statecharts, every `@matrix-fsm` machine is a **visual, column-aligned 2D transition table**:

```ts
/* FROM                 VIA               TO                            OPTIONS */
['customerBrowsing',    'SELECT_DRINK',   stay(),                       { call: (m) => m._selectDrink }],
['customerBrowsing',    'PLACE_ORDER',    awaiting('checkingLoyalty'),  { guard: hasSelectedDrink, call: (m) => m._checkLoyalty }],
['customerBrowsing',    'PLACE_ORDER',    stay(),                       { call: (m) => m._setMissingDrinkError }],
```

## Packages

| Package | Purpose | API Reference |
| :--- | :--- | :--- |
| **`@matrix-fsm/core`** | Pure TypeScript (`0%` Angular) 4-column tuple DSL, FIFO Run-to-Completion runner (`createMachineInstance`), `toMermaid`, `getShortestPaths`, and compile-time extractors. | [Core API](/matrix-fsm/api/core/) |
| **`@matrix-fsm/angular`** | First-class `@ngrx/signals` integration (`createMachineFeature`, `withStateMachine`, `provideStateMachine`, `createFeatureTester`) with `Promise` + `AbortSignal`, RxJS `Observable`, and `ResourceRef`. | [Angular API](/matrix-fsm/api/angular/) |
| **`@matrix-fsm/angular/effect`** | Optional Effect-TS entrypoint (`createEffectMachineFeature`, `createEffectExecutorAdapter`, `runEffect`) with fiber interruption and `Data.TaggedError` (`_tag`) routing. | [Effect-TS API](/matrix-fsm/api/angular-effect/) |
| **`@matrix-fsm/eslint-plugin`** | 14 canonical static AST & graph-conservation ESLint rules (`configs.recommended`) including `--fix` auto-alignment for 2D transition tables. | [ESLint Plugin API](/matrix-fsm/api/eslint-plugin/) |
